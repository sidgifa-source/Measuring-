# 🗺️ تطبيق الخرائط (PWA)

تطبيق خرائط مفتوح المصدر يعمل **بدون إنترنت** بعد التحميل الأول.

## ✨ المميزات
- 🎯 تحديد الموقع الحالي بدائرة زرقاء نابضة
- 📏 قياس مسافة (يدوي / بالمشي عبر GPS)
- 📐 قياس مساحة (يدوي / بالمشي عبر GPS)
- 💾 حفظ المشاريع محلياً (IndexedDB)
- 📂 تحميل وحذف المشاريع
- 🌐 يعمل Offline بعد أول تحميل (بلاطات OSM مخزنة)

## 🚀 النشر على GitHub Pages
1. أنشئ مستودع جديد على GitHub
2. ارفع كل الملفات
3. من Settings → Pages → اختر `main` branch
4. افتح الرابط: `https://username.github.io/repo-name/`

## 📱 تحويل إلى تطبيق (web2app / PWA Builder)
1. ارفع المشروع على GitHub Pages
2. ادخل على https://www.pwabuilder.com/
3. الصق رابط الموقع
4. حمّل التطبيق لـ Android / Windows / iOS

## 🔐 الأذونات المطلوبة
- الموقع (Geolocation) — اختياري لكن مطلوب للتمركز والقياس بالمشي
